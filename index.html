Search live · connect GitHub

on-demand

To search a route on demand, Raven asks GitHub to run the price watcher for you. That needs a token you create once. It stays on this device.

  1. Open GitHub → new fine-grained token ↗.
  2. Resource owner: your account. Repository access: “Only select repositories” → cmgsilv-builder/Raven.
  3. Repository permissions → Actions: Read and write. Leave everything else at “No access”.
  4. Generate the token, copy it, and paste it below.
🔒 Your token stays on this device (browser localStorage). Raven sends it only to GitHub’s own API to start a search — never uploaded anywhere else, never committed.
